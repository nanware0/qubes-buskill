# Contributing

To contribute:
- Clone the repository.
- Make your modifications.
- Commit your changes.
- Open a pull request.

For a commit to be accepted, you need :
- To sign it with a GPG key attached to your GitHub account.
- To respect the [specification](./specification.md) policy.
- To respect the purpose of the project.

A commit, even perfect, can be rejected if the maintainer think that this is not aligned with the project.
